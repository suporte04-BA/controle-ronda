5. PASSO A PASSO - MIGRACAO SERVIDOR LINUX
============================================

REQUISITOS DO SERVIDOR:
  - Ubuntu 22.04+ (recomendado)
  - 2GB RAM minimo
  - 1 vCPU minimo
  - 20GB SSD
  - IP fixo ou DDNS

PASSO 1: COPIAR ARQUIVOS
  Na Windows, abra o PowerShell:
  > scp -r "C:\Users\usuario\Downloads\evolution-api\migracao-server\*" usuario@IP_SERVIDOR:/opt/transobras/

PASSO 2: CONECTAR NO SERVIDOR
  > ssh usuario@IP_SERVIDOR

PASSO 3: INSTALAR DEPENDENCIAS
  > cd /opt/transobras
  > chmod +x *.sh
  > ./01-setup-linux.sh
  (Faça logout/login apos instalar Docker)

PASSO 4: RESTAURAR DADOS
  > cd /opt/transobras
  > ./03-restore-linux.sh

PASSO 5: CONFIGURAR NGROK
  > ngrok config add-authtoken SEU_AUTH_TOKEN
  > ngrok http http://localhost:8080 --domain=president-unbundle-quill.ngrok-free.dev

PASSO 6: INICIAR SISTEMA
  > cd /opt/transobras
  > chmod +x start.sh
  > ./start.sh

PASSO 7: AUTO-START NO BOOT
  > sudo cp transobras.service /etc/systemd/system/
  > sudo systemctl enable transobras

PASSO 8: TESTAR
  Abra o navegador:
  > http://localhost:8080/instance/fetchInstances
  > https://transobras.suporte04.workers.dev/api/whatsapp/status

============================================
7. TROUBLESHOOTING
============================================

PROBLEMA: Porta 8080 nao escuta
  SOLUCAO: docker-compose down && docker-compose up -d

PROBLEMA: ngrok nao conecta
  SOLUCAO: pkill ngrok && ngrok http http://localhost:8080 --domain=president-unbundle-quill.ngrok-free.dev

PROBLEMA: WhatsApp desconectado
  SOLUCAO: curl -X POST http://localhost:8080/instance/connect/transobras -H "apikey:transobra-evolution-2026-chave-secreta"

PROBLEMA: Worker nao responde
  SOLUCAO: npx wrangler deploy (redeploy)

PROBLEMA: Evolution API não inicia
  SOLUCAO: docker logs evolution_api (ver erro)
           docker-compose down && docker volume rm evolution-api_postgres_data && docker-compose up -d
